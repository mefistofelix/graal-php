# PERF-01 evidence

Local date: 2026-09-26 Europe/Rome; raw timestamps are 2026-09-25 UTC.
Method, conclusions and commands: [report](../../curl-p99.md).

- `cold-ab`: 32 same-image trials, four alternating repetitions, timed/untimed.
- `diagnostic`: 8 timeline + guest JIT/GC trials, two alternating repetitions.
- `peer-diagnostic`: 4 further timeline/JIT/GC trials, 10000 parked only,
  with `peer-gc.log` from the shared driver/HTTP-peer JVM.
- `smoke-ordinary`, `smoke-timeline-initial`, `smoke-timeline`: two short
  GraalPHP/TrueAsync trials each. The initial clock bracket used `/begin`,
  then moved to `/suspended`; keep that prototype separate from final schemas.

`graalphp-before` and `graalphp` use the same binary, with CompilerIdleDelay
10000 and 500 respectively. The `-untimed` suffix means no latency sampling.
Each directory retains environment, CSVs, child logs and driver output.
`*-summary.json` is regenerated by `tests/curl_benchmark_report.py`; no summary
is generated for the superseded initial clock schema.

These are separate campaigns, not additional repetitions to pool together.
No payload warmup excluded; no outliers or failed trials removed. Diagnostic
arrays/logging change allocation and timing, so do not use diagnostic results
as the uninstrumented runtime performance comparison.

Clock CSVs retain lower/upper alignment bounds, not exact shared-origin clock
values. The summary's `payload_events`/`payload_invalidations` fields select
JIT events between `/suspended` and `/end`; that window also includes coroutine
release. Native GC totals cover the complete child log, including shutdown.
Peer GC entries select completed pause log timestamps within those controls.

Archived text is UTF-8/LF; line endings, trailing horizontal whitespace in
logs and private absolute workspace prefixes were normalized. Numeric measurements and historical archives were
not changed. The generated directories originally lived under disposable
`build/`; these copies are the persistent evidence.
