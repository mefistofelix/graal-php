IMPLEMENTATION / FAILURE EVIDENCE
Argument unpacking preserves source/key order rather than normalizing a
Traversable to an array first. This is required for duplicate named keys and
integer keys following named keys. Array spread separately uses PHP array merge
semantics. By-reference call unpack binds elements only when the source is a
simple array variable; property/static-property/offset/expression sources use a
temporary, matching the differential corpus. Traversable by-reference calls
use temporary locations and emit the PHP warning rather than mutating iterator state.

The first Windows Native Image attempt failed before producing a product:
CallArguments.expand made java.util.HashMap.<init> and
java.util.Collection.toArray(IntFunction) reachable from Truffle runtime
compilation, which Native Image blocklists. The generic binding operation was
moved behind a TruffleBoundary; the second Windows build and the Linux build
both completed with guest JIT enabled. The failed build transcript is retained
and is not counted as a successful mode.
