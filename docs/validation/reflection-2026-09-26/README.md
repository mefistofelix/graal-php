# Reflection validation

Functional evidence for [Reflection and runtime attributes](../../reflection.md).

`results.txt` is the concise status. `products.json` and `hashes.json` identify the products and maintained source/test snapshot. The retained logs distinguish Windows/Linux and JVM/native execution.

Text logs are normalized to UTF-8/LF, ANSI sequences are removed and private absolute workspace prefixes are replaced. Native Image build resource output is retained only as build evidence; no performance conclusion is drawn from it.
