PARITY / LIMITS
The Windows and Linux Native Images were built sequentially from matching
maintained sources, tests, examples and root build inputs. The final Linux
binary was copied to build/graalphp-linux-x64 and executed from the root.
No performance campaign was run. CompilerIdleDelay, JIT/GC defaults and native
dependency versions were not changed by this block.

This block implements user Iterator/IteratorAggregate/Countable protocols,
foreach over arrays/objects/user iterators, related iterator/count/object-var
builtins, live field iteration, attribute metadata storage and tentative-return
diagnostics including ReturnTypeWillChange. It does not implement all concrete
SPL iterators, generators/Fiber, ArrayAccess, Reflection attributes, argument
unpacking, full builtin typing or complete PHP lifetime semantics.

The Native Image Windows build was accidentally started twice briefly because a
foreground tool call timed out while its child continued; the earlier process
exited before the retained final build completed. No performance result is
derived from either build, and the final product/tests above refer to the
successful retained build. Native Image builds for the final Windows/Linux
products otherwise ran sequentially.
